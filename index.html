Sobre el Curso

El curso Full Stack del INTECAP está diseñado para formar desarrolladores capaces de crear aplicaciones web completas utilizando tecnologías modernas.

Horarios del Curso

Sábados: 08:00 a 11:00 AM

Temario

HTML y CSS

Aprende a crear páginas web estructuradas y diseños modernos.

JavaScript

Agrega interactividad y lógica a tus aplicaciones web.

Backend

Desarrollo de servidores y APIs utilizando Node.js.

Bases de Datos

Aprende a trabajar con bases de datos SQL y NoSQL.
